# ------------------------------------------------------------------------------
# 🚀 SINGLE COMMAND TO RUN LOCALLY:
# ------------------------------------------------------------------------------
# Run this command in your terminal from the project folder:
#
#   pnpm dev
#
# Then open: http://localhost:3000
# ------------------------------------------------------------------------------

# ------------------------------------------------------------------------------
# System & Runtime Prerequisites:
# ------------------------------------------------------------------------------
# Node.js: >= 18.18.0 (Installed: v26.13.0)
# Package Manager: pnpm >= 9.0.0 (Installed: v12.21.0 in ~/.local/bin)
#
# If running on a new PC:
# 1. Install Node.js: https://nodejs.org/
# 2. Install pnpm (if not already installed):
#      npm install -g pnpm
# 3. Install project dependencies:
#      pnpm install
# 4. Start local development server:
#      pnpm dev
# ------------------------------------------------------------------------------

# ------------------------------------------------------------------------------
# Available Scripts:
# ------------------------------------------------------------------------------
# Start local development server (with hot reload):
#   pnpm dev
#
# Build production bundle:
#   pnpm build
#
# Run production build locally:
#   pnpm start
#
# Run ESLint check:
#   pnpm lint
# ------------------------------------------------------------------------------
